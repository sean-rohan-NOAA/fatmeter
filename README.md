# Alaska gadid energetic status

Bianca K. Prohaska, Sean K. Rohan, Esther D. Goldstein, Cody W. Pinger, and Johanna J. Page

The analyses in this repository compare methods for evaluating the energetic status of eastern Bering Sea Pacific cod and walleye pollock based on liver and muscle lipid content. The methods compared are bioelectrical impedence analysis (fatmeter), length-weight regression residuals, Fourier Transform Near-Infrared Spectroscopy (FT-NIRS), and sulfo-phospho-vanillin (SPV) microplate assay.
